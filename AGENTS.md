# AGENTS.md — pitwall

pitwall is a second-screen race-engineer dashboard for the F1 game (F1 25 UDP telemetry): a collector that ingests the game's telemetry and a tile-based, customizable web visualisation served on the LAN.

Planning lives on the wayfinder map in GitHub Issues (label `wayfinder:map`). Read it before starting work.
